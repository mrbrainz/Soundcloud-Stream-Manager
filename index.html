what it does

toggle any of these from the popup - nothing needs a page refresh

⏰

repost age check

Annotates "Reposted X ago" with how old the track's original upload actually is - no more getting baited by a 3-year-old repost.

📂

playlist receipts

Badges every track with which of your own playlists already have it.

🧟

delete the ancient ones

Hides anything (repost or original upload) older than a threshold you set.

😴

no snooze tracks

Hides anything past a length threshold you set - handy for skipping full mixes in a stream of singles.

📦

already got it

Hides tracks you've already sorted into one of your own playlists.

🚫

not the vibe

Hides tracks tagged with a genre you don't want to see - hover any genre tag in your feed for a one-click "hide this" shortcut, no popup needed.

🔍

find it everywhere

One-click search links to Deezer, Apple Music, Beatport, and Spotify for any track.

⬇️

yoink button

Brings back a direct download link for any track SoundCloud itself allows downloading.

get it running

not on the Chrome Web Store (yet) - load it unpacked, takes a minute

  1. Download the latest release from the Releases tab and unzip it.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder.
  5. Visit soundcloud.com and open the extension's popup from the toolbar to start flipping toggles.

Personal-use distribution for now, not a Chrome Web Store listing - loading unpacked means Chrome will occasionally nag you that "Developer mode extensions" are running, which is expected and safe for code you downloaded yourself and can read. Building from a clone instead of a release zip? Select the extension/ folder in step 4 instead.
